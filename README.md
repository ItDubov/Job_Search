# Job Search with DB Connection

Этот проект предназначен для получения данных о компаниях и вакансиях с платформы HH.ru (HeadHunter) с использованием публичного API, их обработки и сохранения в базе данных PostgreSQL.

## Описание

Проект состоит из нескольких компонентов:
1. **HHAPIClient** - класс для взаимодействия с API HH.ru, получения данных о работодателях и вакансиях.
2. **DBManager** - класс для работы с базой данных PostgreSQL, сохранения данных о компаниях и вакансиях.
3. **DB Setup** - настройка базы данных, создание необходимых таблиц для хранения данных.
4. **Main Logic** - основной скрипт для получения данных с HH.ru и сохранения их в базу данных.

## Как работает проект

Проект выполняет следующие шаги:
1. Инициализирует базу данных и создает таблицы `companies` и `vacancies`.
2. Получает список компаний и их вакансий с HH.ru через публичный API.
3. Для каждой компании сохраняет данные (название, отрасль, описание и URL) в таблице `companies`.
4. Для каждой компании сохраняет вакансии (название вакансии, зарплата, описание, ссылка на вакансию) в таблице `vacancies`.

## Как запустить проект

1. Установите необходимые зависимости:

    ```bash
    pip install -r requirements.txt
    ```

2. Настройте файл `config.py` для подключения к вашей базе данных PostgreSQL. Пример конфигурации:

    ```python
    DB_CONFIG = {
        "dbname": "your_dbname",
        "user": "your_user",
        "password": "your_password",
        "host": "localhost",
        "port": 5432
    }
    HH_API_HEADERS = {
        "User-Agent": "project/1.0"
    }
    ```

3. Инициализируйте базу данных, создав таблицы:

    ```bash
    python -m scr.db_setup
    ```

4. Запустите основной скрипт для получения и сохранения данных:

    ```bash
    python main.py
    ```

## Примечания

- В базе данных должны быть две таблицы: `companies` для хранения информации о компаниях и `vacancies` для хранения информации о вакансиях.
- Для взаимодействия с API HH.ru используются стандартные HTTP-запросы через библиотеку `requests`.
- В проекте используется PostgreSQL в качестве базы данных для хранения данных.
